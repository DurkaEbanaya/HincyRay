RU Direct — русские сайты напрямую

Всегда через VPN

Домены из списка всегда идут через VPN и имеют приоритет выше RU Direct. Фоновое обучение сохраняет подтверждённые исключения без автоматического перезапуска ядра.

🚂 Паровозик

Только для сайтов, отсутствующих во включённых GeoBase: сначала DIRECT, после подтверждённой ошибки — текущее VPN и выбранные резервные серверы. GeoBase всегда имеет приоритет.

Файрвол

Файрвол HincyRay — это iptables-перехват трафика, который Keenetic пометил политикой Xkeen/HincyRay. TCP перенаправляется в REDIRECT listener, UDP — в TPROXY при наличии модуля. Остановка файрвола не останавливает Mihomo и локальные SOCKS/HTTP, но отключает прозрачный перехват клиентов политики.

Логгер профиля

Укажите IP устройства, выберите текущий активный сервер, запустите запись, затем воспроизведите проблему. В отчёт попадут только новые соединения этого устройства после запуска.

Логгер не содержит ключи или URL подписок. Он фиксирует только новые прокси-соединения точно указанного клиента; события без его точного IP исключаются.
