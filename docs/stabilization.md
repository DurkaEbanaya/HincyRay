# Стабилизация v1.3.35

## Сохранение и откат

Сохранение использует уникальный приватный временный файл, fsync файла,
атомарное переименование и fsync каталога. Ошибка фонового сохранения оставляет
состояние dirty для повторной попытки. Ошибка явного сохранения возвращается
клиенту. Откат правил не затирает результаты тестов, избранное и свежие кеши.
Откат восстановления резервной копии использует трёхстороннее сравнение полей;
конфликтующие массивы сохраняют параллельную запись, без угадывания идентичности.

## Пул «Лучшие из лучших»

Подтверждённый участник остаётся выбранным и проверяется примерно раз в минуту.
После двух отказов он получает 15-минутный cooldown. В отсутствие подтверждённого
выхода кандидаты перебираются по кругу, не чаще одного на 10-секундный цикл
watchdog. Каждому нужен собственный raw-leaf HTTPS 200–399; до успеха — REJECT.
Таймаут пробы и работа watchdog могут увеличить фактический интервал.

API и интерфейс показывают последнюю категорию результата, время следующей
попытки и не более 20 переходов. Это временная диагностика процесса, не журнал
качества и не доказательство успешного failover под нагрузкой.

## Правила и объяснение маршрута

Редактор допускает только одно сохранение одновременно и сохраняет черновик при
ошибке. `GET /api/routing` возвращает `rules_revision`; Web UI передаёт его как
`expected_revision` в POST. Устаревший снимок получает 409 до изменения состояния.
Старые клиенты без ревизии совместимы, но не получают защиту от stale writes.

Отсутствующий протокол/порт, SRC/IN-port, раннее неизвестное GeoSite/GeoIP,
regex/wildcard и managed GeoBase требуют проверки Mihomo. Локальное объяснение
не приписывает им точное совпадение. Простые домены совпадают только по границе
суффикса, `=example.com` — только точно; CIDR поддерживает IPv4 и IPv6.

Глобальный PortMode — дополнительные правила **после** пользовательских,
системного QUIC, исключений и GeoBase/RU Direct. Финальный MATCH независим:
AllowList не означает «остальные напрямую», если MATCH оставлен proxy.
Оба глобальных списка принимают только валидные порты назначения/диапазоны.

## Удаление Паровозика

Удалены настройки, автоматический классификатор, провайдеры, группы, варианты
целей и интерфейс. Старые явные rule/device/Torrent цели переходят на `active`;
сгенерированные строки и поля классификатора удаляются при startup и restore.
Прежние данные остаются в полном deployment rollback. Исторические release
records описывают прежние версии и не означают наличие функции в текущей.
