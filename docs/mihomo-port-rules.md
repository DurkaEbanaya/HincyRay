# Правила портов Mihomo в HincyRay

Откройте **Маршрутизация → Правила маршрутизации → Добавить правило**.

- **Порты назначения** — удалённые порты сервера, например `1119, 3724,
  12000-64000`. Допускаются запятые, `/`, `;` и переносы строк; каждый порт
  должен быть в пределах 1–65535, начало диапазона не больше конца.
- **Протокол** — TCP, UDP или оба. Совпадение одного из портов достаточно;
  протокол и домен/IP дополнительно ограничивают правило.
- **Режим портов** — только указанные порты либо все, кроме указанных.
  Пустое поле означает все порты.
- **Цель** — DIRECT, текущий VPN, REJECT, «Лучшие из лучших» или фиксированный
  сервер из общего списка целей маршрутизации.
- Оставьте домены/IP пустыми для глобального портового правила. Оно действует
  на трафик, который обрабатывает Mihomo, а не на все устройства Keenetic
  независимо от выбранной ими политики.
- **Приоритет нового правила** позволяет добавить его в начало или конец.
  Кнопки ↑/↓ меняют порядок существующих пользовательских правил; ✎ открывает
  полный редактор. Mihomo использует первое совпадение. Маршруты устройств
  предшествуют пользовательским правилам; финальное MATCH показано последним.

Сохранение применяет конфигурацию и переподключает текущие соединения Mihomo
для повторной оценки маршрутов. Неверные порты отклоняются до сохранения.
Существующие записи `src-port:` и `in-port:` сохраняют свои значения; обычные
номера без префикса всегда означают порт назначения.

**DIRECT не является обходом Mihomo:** TCP всё ещё проходит REDIRECT, UDP —
TPROXY, после чего ядро открывает прямое исходящее соединение. Эти правила
не создают перенаправление входящих WAN-портов и не меняют DNS-политику.

## Пример глобального игрового UDP-правила

```text
Имя: Игровой UDP
Цель: DIRECT
Протокол: UDP
Порты назначения: 3478-3479,5060,5062,6250,12000-64000
Режим портов: только эти
Домены/IP: пусто
Приоритет: В начало списка
```

Генератор объединяет альтернативы в одно поле Mihomo:

```yaml
rules:
  - AND,((NETWORK,udp),(DST-PORT,3478-3479/5060/5062/6250/12000-64000)),DIRECT
```

Широкий диапазон также направит напрямую другой UDP-трафик, совпавший по
порту назначения. Пример не подтверждает работоспособность конкретной игры
или голоса через Mihomo: это проверяется отдельно в реальном сеансе.

Для Vivox опубликованы UDP 12000–54000 и TCP 443 к сетям 85.236.96.0/21 и
85.236.104.0/23. Если нужно отдельное DIRECT-правило управляющего HTTPS,
ограничьте его этими сетями/доменами: глобальный TCP 443 затронул бы обычный
HTTPS. Источник: [официальные требования Vivox](https://support.unity.com/hc/en-us/articles/4407491745940-Vivox-What-IPs-and-ports-are-required-for-Vivox-to-work).
