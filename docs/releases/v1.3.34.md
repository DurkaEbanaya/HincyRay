# v1.3.34 · 2026-09-28

## Mihomo port rules

The existing routing editor now exposes destination port lists/ranges with
validation, TCP/UDP, include/exclude, global scope, top/bottom insertion,
priority arrows, and full editing. MATCH is displayed last, reflecting actual
evaluation order. DIRECT remains a Mihomo outbound, not a firewall bypass.
See [user documentation](../mihomo-port-rules.md).

The generator formerly ANDed independent ports together when a protocol or
address filter was present. Alternatives now use one slash-separated matcher
per port field; distinct fields and protocol/address constraints are ANDed.
Standalone exclusions now negate the set, with the nested parentheses required
by Mihomo's NOT parser. Malformed batches return HTTP 400 before persistence or
undo mutation; invalid legacy inputs reject config generation. Local tracing
recognizes global destination-port rules and slash alternatives.
