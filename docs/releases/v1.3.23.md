# HincyRay v1.3.23

Date: `2026-09-24`.

The v1.3.22 subscription Results sort worked only in the browser tab where the check was started. Reopening the page reset the sort to Import order despite fresh service evidence in `/api/stats`, giving the impression that profiles were unsorted after a repeat test. Results is now the default view on a fresh browser session, and the user's current sort mode is saved locally. An accepted subscription Check Services start switches to Results and saves that choice; deliberately choosing Import order persists through page reloads.
