# HincyRay v1.2.0

v1.2.0 introduces explicit Quick and Full service diagnostics with bounded parallel server workers, reliable YouTube media validation, and more compatible subscription imports.

## Release scope

- Quick Test records ICMP, direct TCP, and end-to-end proxy HTTPS ping diagnostics. Any successful ping opens the gate, followed by fail-fast YouTube, Telegram, and AI Studio checks.
- Full Test runs the same ping and service checks independently so one failed stage does not hide later results.
- The Web UI exposes one global Full Test action and Quick Test actions for profiles, groups, subscriptions, selected profiles, and Dead Servers. Server concurrency is configurable from 1 to 6.
- Profile cards show compact ping/YT/TG/AI results and can sort by complete outcome, successful check count, then ping. Service diagnostics remain separate from health counters, cooldown, failover, and auto-selection history.
- The anonymous YouTube Innertube boundary is serialized; its bounded media request reuses visitor cookies and the matching client identity, preventing false CDN `403` failures while keeping the Rust + `curl` implementation.
- Temporary benchmark Mihomo processes use their writable config directory instead of the router root home.
- Subscription loading rejects unusable unspecified-address sentinels before the existing Happ compatibility fallback.
- `docs/t99w175-b3-pcc-lock.md` records the tested T99W175/MV31-W LTE B3 PCC lock and B1+B7 carrier-aggregation procedure.
