# HincyRay v0.21.4

v0.21.4 fixes the process-observability contract for temporary Mihomo instances used by profile benchmarks and quality testing.

## Fixed contract

- Temporary Mihomo stdout and stderr are captured in one ordered process log.
- Router HEAD/GET benchmarks, speed tests, Deep Bench, and desktop Mihomo tests use the same combined-output contract.
- Early process exits include a bounded tail from the combined log, so startup/configuration failures are no longer reduced to an opaque exit status.
- Existing random-port allocation, readiness deadlines, and child cleanup guards are unchanged.

## Incident context

- Router infrastructure remained healthy while the selected upstream profile was unavailable; Mihomo correctly held the fallback group on `DIRECT`.
- The temporary protocol benchmark returned identical early-exit failures for multiple independent profiles, but discarded Mihomo stdout where startup diagnostics are emitted.
- The selected upstream was replaced through the transactional active-profile API and remained `proxy-active` throughout a 100-second observation window.
