# HincyRay v1.1.0

v1.1.0 adds the disabled-by-default «Паровозик» direct-first classifier and switches AI Studio Quick Test availability to the bounded `vernette/ipregion` region method.

## Release scope

- Domains absent from enabled applied GeoBases are tried DIRECT first; confirmed failures can use the current VPN and up to five selected live server routes.
- Learned decisions are projected as separate managed `Паровозик Direct` and `Паровозик VPN` rules below GeoBase precedence.
- The Web UI groups selectable live servers into compact subscription columns, excludes Dead Servers, exposes no endpoint secrets or technical connection fields, and preserves unsaved selections across periodic status refreshes.
- The superseded browser-extension experiment and its extension-only routing/CORS API surface were removed.
- AI Studio Quick Test resolves the tested profile's Google exit region and matches it against Google's published supported-region list. Telegram keeps its authorized media probe because ipregion has no Telegram check.

## Public distribution

- Installer version: `1.1.0`.
- With no local `HINCYRAY_BIN_PATH`, the installer downloads `hincyray` from the exact public `v1.1.0` GitHub Release.
- The release asset is the patched aarch64 GNU/Entware binary with interpreter `/opt/lib/ld-linux-aarch64.so.1` and RPATH `/opt/lib`.
