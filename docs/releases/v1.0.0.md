# HincyRay v1.0.0

v1.0.0 is the first stable public HincyRay release for Keenetic/Entware aarch64. It promotes the hardened router runtime from v0.22.1 and completes the production Fluent/Acrylic Web UI, public installer, documentation, and release pipeline.

## Stable scope

- Mihomo is the single router proxy core.
- Transparent clients use separate iptables NAT REDIRECT (TCP 10810) and mangle TPROXY (UDP 10811) listeners; there is no TUN/tun2socks path.
- The ndm netfilter hook is the primary firewall-reload mechanism, with watchdog reinstall as a safety net.
- Runtime apply is serialized and transactional across generated config, core readiness, firewall state, and persisted desired state.
- Routing refs (`srv-v1`) and lifecycle refs (`srv-v2`) remain separate contracts.
- Router DNS is always generated because firewall rules redirect DNS to Mihomo on port 1053.
- `geoip.metadb` is local and auto-update is disabled; router startup does not depend on GitHub.

## Web UI

- Completed Fluent/Acrylic production panel with desktop, tablet, and mobile navigation, RU/EN localization, themes, accessibility focus states, and no external frontend build/CDN.
- Restored the HincyRay mark in the sidebar and added the matching embedded favicon.
- Profile groups now span the available section width. Profiles use adaptive multi-column grids on desktop/tablet and a single-column mobile layout.
- Optional metrics stay configurable, while service checks remain attached to the profile name.
- Quick Test and other long-running operations display a moving activity indicator throughout the supported runtime path.
- Production mode uses daemon APIs; local mock data is limited to `file:` preview.

## Router capabilities

- Transactional active-profile switching, fallback health, safe mode, desired/applied routing preview, explanation, undo, backups, memory guard, and managed GeoBase.
- Dead Servers preserves profile provenance and supports validated atomic move/restore/clear flows.
- Deep Bench persists bounded quality history separately from state.
- Quick Test sequentially validates YouTube, Telegram, and AI Studio through each selected profile.
- Web UI authentication uses Argon2id password hashes, random bounded sessions, login throttling, same-origin mutation checks, and `sessionStorage` Bearer tokens.
- Config and log responses are bounded and structurally redacted; Telegram credentials/session data stay outside `state.json`.

## Public distribution

- Repository visibility: public.
- Installer version: `1.0.0`.
- With no local `HINCYRAY_BIN_PATH`, the installer downloads `hincyray` from the exact public `v1.0.0` GitHub Release.
- The release asset is the patched aarch64 GNU/Entware binary with interpreter `/opt/lib/ld-linux-aarch64.so.1` and RPATH `/opt/lib`.
