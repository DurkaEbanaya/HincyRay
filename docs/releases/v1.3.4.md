# HincyRay v1.3.4

v1.3.4 hardens routing-resource identity, fake-IP handling, XHTTP profile tuning, and router memory behavior.

## Release scope

- Domain suffixes are canonicalized before persistence and config generation, so `.ai`, `ai`, and `example.ai` produce valid `DOMAIN-SUFFIX` rules. Existing leading-dot rules migrate at startup.
- The full Mihomo fake-IP block `198.18.0.0/15` is treated as synthetic: it cannot be persisted as an IP route, connection rows prefer a recovered host, and GeoIP enrichment can fall through to a real remote destination.
- Bulk subscription refresh reloads routing data together with profiles and subscriptions, preventing stale opaque server references in newly submitted routing rules.
- Manual XHTTP profiles expose measured `scMaxEachPostBytes` choices of 4096, 8192, 16384, and 32768 bytes. Unknown existing values remain visible and unrelated `extra` keys are preserved.
- Upload benchmark timeouts are surfaced as errors rather than converted into misleading throughput at the exact deadline boundary.
- The router daemon limits glibc allocator arenas and periodically trims unused pages after transient work to reduce retained RSS on the 512 MiB/no-swap target.
