## Corrective scope

- Restored subscription/group header lightning actions for whole-scope testing and table presentation, retaining shared parameters and scope intent.
- All profiles have fixed neutral YT/TG/AI indicators with explicit not-tested, stale, skipped, and current evidence states. Missing/skipped service measurements are not labeled current failures.
- Fresh completed results overlay safely after profiles load only when canonical lifecycle-v2 `server_ref` and exact current profile ID both match. Status returns that canonical ref, never private raw connection identity.
- Public independent `last_service_test_unix` controls service freshness; generic health timestamps, background traffic, or EWMA activity cannot refresh service evidence.
- Service indicators use a six-hour freshness window and 60-second future-time tolerance; zero timestamps remain not-tested. Fixture browser tests verify exact-ID/ref overlay and indicator states; live verification checked embedded markers, not actual browser DOM behavior.
- Private temporary-core logging uses warnings and reads only a bounded 64 KiB tail for fixed-category diagnostics. Raw core addresses/logs are not exposed. Original preflight HTTP/curl errors are preserved, with categorical upstream deadline evidence appended; TLS EOF before service execution is not a tested YouTube failure.
- Complete scope retains per-candidate availability Quick short-circuit after YouTube/Telegram failure or Full continued checking. Find N retains preflight, service-history ordering, and targets. Protocol, SNI, certificate verification, and timeouts are not changed without proof.
- YouTube remains public MrBeast identity plus three distinct decoded previews, `youtube_thumbnails` contract 1, with existing request/decoder/cancellation/memory bounds. Weak availability evidence cannot drive generic EWMA/native health, native promotion, automatic Dead Servers, or AutoSelect.
- Separate native contract-7 API and legacy history compatibility are unchanged. No old native mode is added to user search; no authentication/cookie/session, captcha, JavaScript, yt-dlp runtime, or playback workaround is introduced.

Usage: [`../youtube-availability.md`](../youtube-availability.md). Discovery scope/goal behavior: [`../adaptive-discovery.md`](../adaptive-discovery.md).
