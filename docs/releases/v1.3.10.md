## Feature scope

- Every user-facing search scope uses only the public `https://www.youtube.com/@MrBeast` channel page and three decoded video previews for its YouTube check. Structured data must confirm the channel and three distinct video identities; avatars/channel images cannot substitute for video previews.
- New `availability_quick`/`availability_full` methods use short-circuit/continue policy for complete scope; adaptive results use `search_availability`. Shared browser parameters, Find N targets/prefixes, and global/selected/subscription/group/single/explicit Dead Servers diagnostic scopes remain separate.
- Evidence is `youtube_thumbnails`, contract 1. Success proves page/previews access only, not video playback, account access, or strong upstream health.
- No Innertube request, video download, cookies/session import, JavaScript execution, login, or authentication workaround belongs to this method. The search UI offers no alternate YouTube verification method; compatibility help/controls remain separate.
- Shipped `quick`/`full` API and native contract-7 history remain separate for concrete API/persisted-data compatibility. Native success cannot become a preview pass, and previews cannot become a native pass.
- Availability persists diagnostic resources, not generic EWMA health or overall native Quick/Full success. Completed availability scopes cannot trigger native promotion, automatic Dead Servers movement, or AutoSelect. Explicit manual actions remain unchanged.
- HTML is bounded to 2 MiB/20 seconds; each preview to 128 KiB/8 seconds, with 5-second connection timeouts. Preview URLs must be HTTPS `i.ytimg.com:443`, match video identity/path, and have no credentials or redirects. Actual JPEG/PNG/WebP decoding requires dimensions at most 1024 pixels and allocation at most 16 MiB.
- YouTube remains serialized; cancellation/reaping and startup memory estimates remain an 80 MiB router reserve plus 48 MiB per worker. Unknown/zero budgets reject HTTP 503; this is not continuous reserve enforcement or parallel YouTube-probe evidence.

Usage and compatibility details: [`../youtube-availability.md`](../youtube-availability.md).
