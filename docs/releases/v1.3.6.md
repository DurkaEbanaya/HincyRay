# HincyRay v1.3.6

v1.3.6 adds opt-in profile-list promotion and automatic Dead Servers transitions after complete Quick/Full tests.

## Release scope

- Two persisted checkboxes in Profiles testing settings control promotion and automatic dead movement. Both default to disabled.
- Promotion is applied within each provenance group: Ping+YouTube+Telegram+AI, then without AI, then without Telegram. Equal tiers use lower ping first; other profiles retain their relative order.
- Automatic Dead Servers movement requires all three current ping checks to fail and no successful response. Active and already-dead profiles are skipped, and responsive canonical aliases prevent movement.
- Cancelled and partial tests do not apply post-actions. Profile renumbering preserves active connection identity and completed result IDs are remapped without collapsing distinct raw aliases.
- The typed bounded `/api/bench/settings` contract persists settings; OpenAPI retains all methods sharing one path.
