# HincyRay v1.2.1

v1.2.1 fixes the built-in Mihomo updater on memory-constrained Keenetic routers and preserves nested subscription URLs.

## Release scope

- Mihomo release decompression now streams `gunzip` output directly into the staged executable instead of collecting the complete decompressed binary in HincyRay memory.
- Decompression failures remove partial staged output before returning an error.
- Existing downloaded-binary verification, backup, core restart, and rollback behavior remains unchanged.
- The regression was observed live while updating Mihomo from `v1.19.28` to `v1.19.29`: buffering the approximately 45 MB decompressed binary triggered a 64 MiB allocation failure and stopped HincyRay.
- Subscription wrappers such as `https://provider.example/happlink?link=https://provider.example/sub/<token>` remain one subscription candidate; separate URLs delimited by whitespace continue to import independently.

## Public distribution

- Installer version: `1.2.1`.
- With no local `HINCYRAY_BIN_PATH`, the installer downloads `hincyray` from the exact public `v1.2.1` GitHub Release.
- The release asset is the patched aarch64 GNU/Entware binary with interpreter `/opt/lib/ld-linux-aarch64.so.1` and RPATH `/opt/lib`.
