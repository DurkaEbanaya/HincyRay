# HincyRay v1.3.0

v1.3.0 adds bounded AI-ready profile diagnostics and profile editing, simplifies Mihomo Parameters, hardens core lifecycle ownership, reduces connection-table memory pressure, and expands XHTTP and benchmark compatibility.

## Release scope

### Profile Logger

- An on-demand 1–5 minute diagnostic session records only new `proxy-active` connections from one explicitly supplied LAN client IP.
- The daemon correlates source-scoped routing chains, destinations, traffic, warning/error events, service results, memory/runtime state, and a structurally redacted configuration summary.
- The bounded Markdown report is suitable for direct AI troubleshooting. It excludes raw share links, subscription URLs, authentication, cookies, tokens, passwords, private keys, and other credential-like values.
- Sessions are transient, single-owner, session-ID checked, non-persistent, repeatably readable for 15 minutes, and finalized on timeout, manual stop, profile change, core-generation change, panic, discard, or shutdown.

### Profiles and No group

- Manual profiles can be edited through a sensitive detail endpoint without exposing raw links in the regular profile list.
- Connection-identity changes migrate lifecycle, quality, favorites/statistics, and enabled routing intent transactionally.
- Subscription-managed links remain read-only; display names remain editable.
- `No group` profiles can be locally reparsed and validated as one all-or-nothing batch without a subscription network request.

### Parameters and lifecycle

- The Parameters API/UI now exposes only validated router-relevant settings plus read-only runtime invariants.
- Unsupported relay/NTP/SMUX/provider/rule/authentication/no-op DNS surfaces were removed from this path.
- External Controller is fixed to loopback and its credentials are never exported.
- Linux child ownership uses parent-death signaling and required-listener inode checks, preventing a foreign/orphan EC process from satisfying readiness.
- Config, profile, and parameter activation share serialized validation, readiness, persistence, and exact rollback contracts.

### Performance and compatibility

- Bounded one-pass connection paging avoids repeated full-response parsing and enriches only the requested page; GeoIP metadata is cached until the file changes.
- Happ/Xray XHTTP `extra` options are mapped into Mihomo with correct types, bounds, range handling, redaction, and the v1.19.29 header/cookie uplink chunk-size compatibility default.
- Benchmark concurrency persists across reloads, admits only one job atomically, displays every active profile worker, and reaches the selected 1–6 profile-level concurrency.
