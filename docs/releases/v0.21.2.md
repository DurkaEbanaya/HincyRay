HincyRay v0.21.2
================

v0.21.2 is a router hotfix for GeoBase Active routing safety.

## Fixed

- GeoBase Active rule providers now target Mihomo's `proxy` fallback group instead of the raw `proxy-active` outbound.
- This preserves the `[proxy-active, DIRECT]` safety contract when the active upstream server flaps or times out.
- Broad generated GeoBase rules can no longer bypass direct fallback and make policy-marked clients lose internet.
