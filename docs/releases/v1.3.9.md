## Patch scope

- Adaptive preflight treats any completed HTTPS request with HTTP status 200-599 as transport reachability, not YouTube playback. An unsuccessful preflight retries once on an alternate domain using the same isolated Mihomo core.
- Rejected preflights carry no persisted health/Dead Servers penalty. Private temporary core home/config/log are retained until child reap; status keeps at most the last 20 preflight diagnostics with redacted errors bounded to 2 KiB.
- The native YouTube probe uses direct VISIONOS Innertube without mandatory web watch/bootstrap. Only successful video-MIME media transfer of at least 16 KiB of actual bytes can pass; a reachable HTTPS endpoint or player response cannot.
- Bot/login refusal, HTTP 429, and HTTP client-compatibility refusals are inconclusive, not server failure or pass. Amber/unknown UI and summaries exclude false failures and stale legacy successes. Unknown evidence cannot trigger promotion, Dead Servers, or AutoSelect; unknown history remains unknown and does not count as a discovered good server.
- Native resource contract 7 makes previous contract-6 evidence stale. The serde-defaulted `inconclusive` field tolerates older saves without promoting stale evidence to current success.
- Persistent Linux Mihomo spawning uses a 256 KiB owner-thread stack and queue bound 1. This fixes creator-thread `PDEATHSIG` delivering SIGKILL when a short-lived HTTP thread exits, while preserving actual `Child` ownership and daemon-death kill/pre-exec behavior. It is not an optional application runtime and adds one baseline daemon thread.
- No YouTube cookie/session import, authentication or request workaround, captcha, JavaScript, or yt-dlp runtime is introduced. Existing worker limits, serialized YouTube/Telegram boundaries, cancellation, and unified search scopes remain intact.

This patch improves reachability gating and outcome honesty. It does not establish anonymous media availability, fix all historical rejects, or demonstrate a quantitative speedup. Usage and semantics: [`../adaptive-discovery.md`](../adaptive-discovery.md).
