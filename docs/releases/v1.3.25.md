Optional Telegram notifications use a bot token supplied through the panel. Send `/start` to the bot in a private chat **after** saving the token: the router pairs automatically using Telegram Bot API `getUpdates` and sends `sendMessage` to that same chat when a later check changes. Bot API requests travel via the router's configured SOCKS listener, so they remain usable if Direct Telegram is blocked. A token previously shared in chat should be revoked in BotFather and replaced in the panel.
