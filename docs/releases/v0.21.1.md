# HincyRay v0.21.1

v0.21.1 completes the remaining v0.21 control-plane contract work that was not fully implemented in v0.21.0.

## Added and completed

- Full onboarding readiness checks:
  - Mihomo binary.
  - Active profile.
  - `geoip.metadb`.
  - Keenetic policy mark.
  - `xt_TPROXY`, `xt_socket`, `xt_comment`/TPROXY capability.
  - Mihomo core state.
  - External Controller reachability when enabled.
  - DNS listener health.
  - Transparent firewall state.
  - ndm firewall hook.
- Generated OpenAPI/JSON schema document at `GET /api/openapi.json`.
- `/api/contracts` now advertises the schema endpoint and typed endpoint contracts.
- Typed routing preview diff for rule count, MATCH target, GeoBase apply, core restart, and firewall reload.
- Explicit Connections “create/change rule” flow, alongside quick route target selection and “why this route”.
- Redacted `/api/logs` output for suspicious credential-bearing lines.
- Browser E2E expanded to 12 tests: login, routing rule add/apply, Connections search/action/rule editor, DNS save/apply, profile import, mobile navigation, device accounting, pagination, boot safety, and prompt-free rename.

## Decomposition

- Moved Mihomo External Controller HTTP transport into `hincyray_mihomo_api`.
- Moved routing resource normalization into `hincyray_routing`.
- Existing `hincyray_api`, `hincyray_security`, and `hincyray_webui` boundaries remain.
