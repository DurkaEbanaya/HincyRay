# HincyRay v1.3.3

v1.3.3 improves subscription organization, operation navigation, routing-page hierarchy, and router diagnostics.

## Release scope

- Subscription headers expose persistent up/down ordering. Each request names the adjacent visible subscription, so hidden empty sources cannot consume a click without a visual move.
- Sidebar operation indicators navigate to the page associated with the active benchmark, server switch, routing operation, diagnostic, backup, core, or update task.
- Raw External Controller controls are removed from Proxy Status. Bounded status views remain available through daemon-owned wrappers.
- GeoData/GeoBase and default-collapsed Split Routing controls are placed at the bottom of the routing page.
- DNS Diagnostics renders the structured response from Mihomo's TCP DNS listener and no longer calls unsupported `/dns/query` EC API.
- YouTube Unlock Check uses the native playback probe shared with Quick Test.
