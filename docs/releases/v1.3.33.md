# v1.3.33 · 2026-09-28

## Fix

The user reproduced an immediate `at most 16 pinned servers may be enabled`
error when enabling the saved 16-member best-of-best pool. The live router had
five different fixed-server targets in enabled rules and no overlap with those
members. v1.3.32's live audit had saved only the disabled pool, so it did not
cover this failure.

The pool now has an independent 16-member budget. The existing fixed-route
budget stays at 16, shared by rules, device routes, Torrent fixed targets and
Parovozik additions. The maximum union is bounded to 32; overlapping outbounds
are still deduplicated. The separate Parovozik cap, routing/lifecycle identity
contracts, raw-leaf HTTPS gate and REJECT-first selection remain intact.
