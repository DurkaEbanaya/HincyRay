# v1.3.29 · deployed 2026-09-26

“Лучшие из лучших” is an opt-in routing target for up to six subscription servers selected from fresh Check Services results. The configuration preserves server routing refs (`srv-v1`) independently from lifecycle evidence (`srv-v2`). The controller tests HTTPS through the selected raw leaf with a 200–399 response requirement; ICMP/TCP ping and fallback group health cannot grant access. A selector defaults to REJECT and never falls back to DIRECT or the active VPN. Successful leaf probes select that server; two failures demote the current selection, place it in a bounded cooldown, and leave the group rejecting until an alternate candidate passes a fresh probe. Reload/restart resets the group to REJECT, and Mihomo selector persistence is disabled when the group is present to prevent restoring a stale selection at startup. Existing subscription/routing and unrelated devices are unaffected.

Both rule and connection-table routing-target dialogs sort servers by current successful service checks, then lower fresh proxy latency. Unavailable/dead servers are last. The automation panel exposes current pool membership and selection.
