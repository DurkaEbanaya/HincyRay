# HincyRay v1.3.1

v1.3.1 is a router-safety and Web UI responsiveness patch release. It adds editable XHTTP upload tuning, observable and non-queueing server activation, prompt Quick Test cancellation, memory-aware benchmark concurrency, and robust sidebar operation indicators.

## Release scope

- Manual VLESS XHTTP profiles expose `scMaxEachPostBytes` and `scMinPostsIntervalMs` without introducing new persistent profile state. Unknown `extra` fields remain intact and empty values restore Mihomo defaults.
- Active-profile switching publishes real daemon stages through a bounded status endpoint. Concurrent user selections fail fast instead of waiting behind the configuration apply lock.
- Quick Test cancellation owns, terminates, and reaps only benchmark children. Cancelled results do not enter profile history.
- Temporary Mihomo workers preserve an 80 MiB system memory reserve and scale down from the requested concurrency when the router is under memory pressure.
- Sidebar operation scanners use CSS animation. Long operations have unique identities; active-profile and benchmark status requests are single-flight; stale responses cannot restore terminal indicators; broad refreshes are coalesced.
