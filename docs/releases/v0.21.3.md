# HincyRay v0.21.3

v0.21.3 makes subscription refresh non-destructive when a provider returns a successful HTTP response that contains no supported proxy profiles.

## Fixed contract

- A subscription loader success now requires both a successful HTTP exchange and at least one supported parsed profile.
- Empty bodies, HTML/challenge or maintenance pages, and JSON without supported proxy outbounds are content failures, not an empty successful subscription.
- The loader retains its SingBox-to-Happ Android retry; the content error is returned only after the final response still contains no supported profiles.
- `replace_subscription_profiles` rejects an empty set before mutating state. Existing subscription profiles, their sequential IDs, and the active profile remain unchanged.
- Only explicit subscription/group deletion APIs may erase an existing group.

## Regression coverage

- HTTP `200 OK` local responses with an empty body, HTML body, or maintenance JSON are rejected after both request modes.
- Empty plain/base64/JSON content is rejected as a subscription content error.
- An attempted empty replacement preserves every existing profile, its ID and group, and the active profile selection.
