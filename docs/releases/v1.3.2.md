# HincyRay v1.3.2

v1.3.2 fixes a CSS cascade regression that made the sidebar activity scanner static whenever the browser or operating system advertised `prefers-reduced-motion: reduce`.

## Release scope

- Sidebar operation scanners retain their compositor-friendly CSS motion in reduced-motion mode with a slower 3.4-second cycle.
- Other decorative animations and transitions remain disabled under the accessibility preference.
- The browser suite now verifies the computed animation name and duration for this exact runtime path.
